editor de skills
skills do escritório

      
Escolha uma skill do kit ou crie uma do zero. Preencha os dados, confira o arquivo e baixe o .zip pronto para enviar ao Claude.

    

    

      
o que é uma skill
É um manual de instruções que você entrega ao Claude uma única vez. Ele explica como fazer uma tarefa do seu escritório: os passos, as regras e o formato da resposta. Pense no manual que você daria a um estagiário novo.

      
por que personalizar
Sem skill, você precisa explicar tudo de novo a cada conversa. Com a skill, o Claude já sabe o nome do escritório, a cidade, o tom e o jeito de trabalhar, e aplica sozinho sempre que a tarefa aparece.

      
como funciona
A skill é uma pasta com um arquivo principal (SKILL.md) e, às vezes, arquivos de apoio. Aqui você só preenche os campos; o site monta a pasta e gera o .zip. No Claude, basta enviar esse .zip uma vez.

    

    

      
sem skill · toda vez
Você escreve um pedido longo explicando o escritório, o tom, as regras e o formato.
"Sou do escritório X, em Camaçari, atuo com previdenciário, escreva no tom acolhedor, não prometa resultado, use parágrafos curtos, explique esta decisão para o cliente..."

      
com skill · uma frase
Você só cola a decisão. O Claude reconhece a tarefa e segue a skill.
"Explique esta decisão para o cliente: [cola a decisão]"

    dúvidas frequentes
    
      
    Preciso saber programar?
    Não. A skill é escrita em texto comum. Você preenche os campos à esquerda, confere o texto à direita e baixa o arquivo.
    
      
    O que faço com o arquivo .zip?
    Não precisa abrir. No Claude, vá em Configurações → Skills, clique em Adicionar e envie o .zip como ele veio. A skill aparece na lista, ligada.
    
      
    Como sei que a skill está funcionando?
    Abra uma conversa nova e faça um pedido da tarefa, sem citar o nome da skill (use o teste logo acima). Na resposta, o Claude indica que está usando a skill. Se ele não usar, reescreva a descrição dizendo com mais clareza quando ela deve ser usada.
    
      
    Qual plano do Claude preciso?
    Skills funcionam nos planos pagos (Pro, Max, Team e Enterprise), com a opção "Executar código na nuvem" ligada em Configurações → Recursos.
    
      
    Posso mudar a skill depois?
    Sim. Volte aqui, ajuste os campos, baixe o novo .zip e envie de novo no Claude. Remova a versão antiga para não ficar com duas iguais.
    
      
    Os dados que eu digito vão para algum lugar?
    Não. Tudo é montado no seu navegador e só sai daqui quando você copia o texto ou baixa o arquivo. Mesmo assim, não coloque dados de clientes na skill: use só dados do escritório.
    
      
    Qual skill instalar primeiro?
    Comece pelo Anonimizador LGPD, que protege o sigilo antes de qualquer análise. Depois, a skill da tarefa que você mais repete: prazos, resumo para cliente ou petição no padrão do escritório.
